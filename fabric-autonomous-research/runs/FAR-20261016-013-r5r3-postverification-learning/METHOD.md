# Method

1. Re-read the round's own raw artifacts (status, checker verdict, mutation control, compiler receipt) and hash them into SOURCE_INVENTORY.json.
2. Classify every deviation by ORIGIN (maker vs subject) and by what it cost (CI round-trip, wrong problem hunted, false confidence).
3. Reduce each deviation to one imperative rule and route it to the skill that owns that work.
4. Keep the red states in the evidence set; a learning that hides the failure it came from is narration.

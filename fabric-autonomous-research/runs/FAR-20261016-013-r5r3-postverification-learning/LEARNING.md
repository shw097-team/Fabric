# Learning delta - R5R3

1. A round's evidence is not product content. Where a repo gates its own write set positively, the round's
   pack and its openspec change belong on an evidence-return branch, and every record the round adds belongs
   in the path the repo's documentation already names.
2. Verify a mechanism, not a value. The credential was correct the entire time; the invocation was wrong, and
   the failure text pointed at the credential.
3. The subject's own gate outranks the round's self-check for scope questions. Run it locally, post-commit.
4. Red runs are deliverables. The failed gate run, the failed first acceptance run and the three checker
   findings all stayed in the pack; each of them is what makes the green state credible.
5. A published subject is verified, not repaired. D1/D2/TYPE5 were already merged, so the round re-derived
   them against both the frozen tree and the published wheel's bytes instead of re-implementing them.

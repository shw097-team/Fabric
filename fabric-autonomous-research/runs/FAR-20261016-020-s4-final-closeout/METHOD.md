## Steps

1. **G0 read-only preflight, fail-closed.** Compiler bundle located (three copies byte-identical);
   this round's contract generated by mirroring a shipped lint-clean reference, then `lint`,
   `activation`, `acceptance`, `compile` — all exit 0. Bundle self-suite 22 OK. Duplication probe
   0.0018 / 0.0 against a 0.25 threshold (no control-corpus restatement).
2. **HGK typed admission.** 18/18 sources, intake READY, three transitions, plan, five WorkOrders,
   checkpoint `CK-PR18-A2FBBBB0`.
3. **Route check.** GSTACK `CERTIFIED` for plan-review / security / qa / acceptance flows with a
   negative control that routes `NATIVE`; OpenSpec change validated strict (4/4 artifacts).
4. **Parallel reconnaissance (SWARM).** Three children: identity+release readback, CI raw logs,
   findings/checklist mapping.
5. **Declared fallback.** The CI-log child died with `HTTP 429` (provider usage limit) at 121 s; the
   subject was re-run by a **deterministic script** (`checks/gh_readback_s4f.py`) that also absorbed
   the identity readback. No model, no quota, reproducible.
6. **Independent byte-level check.** The published private ZIP was downloaded and inspected from its
   bytes rather than trusted: 68,357 B, sha256 matches, 56 members, one root, 8 `SKILL.md`, no
   MCP/Apps/Hooks, no traversal.
7. **Write-set classification, at the right tree.** The classifier was first run against the ambient
   checkout and reported a false FAIL; it was then re-run in a detached worktree at the subject's own
   head, where it PASSES (27 changed, 0 frozen, 0 outside).
8. **Closeout package.** Six named files + a single evidence MD + manifest + SHA256SUMS, then a
   fresh-extract verification from the committed blobs (8/8 matched, 0 CRLF).
9. **One scoped remote write.** Branch `s4-final-closeout-evidence-20261016@219e92ba`; remote tip read
   back equal to local. No merge, tag, release or product-branch write.
10. **Independent `VERIFY_ONLY` lane** over the frozen packet, on the same model arm (disclosed).

## Deviations found by the round (the study's real output)

| ID | Deviation | Class | Low-friction remediation |
|---|---|---|---|
| `DEV-S4F-01` | The readback script's own path comparison compared an unsorted expected list against a sorted API list and reported a false FAIL | maker-side tool defect | sort both sides and assert the count; the round then re-ran and the row passed — recorded rather than silently fixed |
| `DEV-S4F-02` | `check_write_set.py` reads the allowlist out of the **ambient checkout's** workflow; run against `main` it flags `docs/USER_GUIDE.md` as outside the set, because the candidate itself widens the allowlist | **method-level, affects any round judging a candidate that edits its own gate** | run the classifier in a detached worktree at the subject head: `git worktree add --detach <tmp> <sha>` then classify — one command, no branch switch, no packet loss |
| `DEV-S4F-03` | A SWARM child died on `HTTP 429` mid-round | orchestration fragility | keep a deterministic, model-free route for every extraction that can be scripted; on 429 switch immediately, keep going, and record the substitution in the artefact |
| `DEV-S4F-04` | A branch push in this repo runs **no** workflow (trigger is `pull_request` / `workflow_dispatch` only), so "the evidence branch's CI" can only ever be a PR-triggered run | claim-attribution risk | attribute CI numbers to the run and its head SHA, never to "our push"; state explicitly when a push produced no run |

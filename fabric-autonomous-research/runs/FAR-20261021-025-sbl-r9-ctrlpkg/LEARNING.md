# LEARNING — accumulated, not restated

Numbering continues the programme's ledger (L25 onward). Each line is a rule that changes
future behaviour, not a diary entry.

L25  A gate may only be cited for the property it directly measures. Every gate in this
     programme passed while the thing it was trusted to prove was false. Before quoting a
     green signal, state what it compared A to B, and check that A and B are the two things
     the claim relates.
L26  When a claim of the form "X and Y agree" is needed, the check must compare X to Y.
     A check that compares X to X's pin and Y to Y's pin cannot detect X-Y divergence, no
     matter how green it is. This single distinction explains D1, D2, the compiler's blind
     spot, and the lane-probe blind spot.
L27  If the governing document declares its own denominator unknown, no completion percentage
     is computable, and producing one is fabrication with a decimal point. Report the
     countable inventory and the UNKNOWN separately.
L28  Research workers must be told to quote verbatim and to name what they could not open.
     Both instructions changed the output: the residual list would otherwise have read as
     complete when one worker had simply not been able to read a 17 MB document set.
L29  Do not manufacture a target to complete a checklist. FABRIC has no SBL install target;
     inventing one would have produced a five-plane claim with a hollow plane.
L30  Do not stage another party's uncommitted code to make a number reproducible. The honest
     alternative is a disclosed, typed blocker, even though it leaves the number
     irreproducible from a clean checkout.
L31  A self-check must contain at least one check that fails if the round succeeded
     dishonestly. C10 asserts no acceptance pass was written anywhere; without it the
     self-check would bless its own output.
L32  A verifier that has never been observed to fail has not been shown to work. The control
     package checker was exercised with a same-length one-byte tamper specifically so that
     the sha256 path, not the size path, had to catch it.
L33  Write the ruling before executing, so execution cannot retro-fit the ruling. This round's
     ruling named what would not be done, and that list survived contact with the work.
L34  Pre-authorisation covers engineering actions, not authority. An owner's blanket approval
     to act does not mint a permit, an issuer signature, a host admission or an acceptance
     verdict. Name the covered set explicitly and refuse the rest out loud.
L35  When a brief you wrote contains a factual error that workers propagated, correct it in
     the record. The brief said the source lived at SBL/src; that path does not exist.
L36  Report the honest count of what is archived. Three of four worker outputs are on disk;
     the fourth was delivered inline and was never written to a file. Saying "four archived"
     would have been false.

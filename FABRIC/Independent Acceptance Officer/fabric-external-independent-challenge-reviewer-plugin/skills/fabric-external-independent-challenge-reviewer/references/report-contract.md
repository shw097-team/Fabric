# External Challenge Report Contract

The report must be usable by a Meta-Oracle or human without trusting the challenger's prose alone.

Required sections:

1. Review scope and exact subject identity.
2. Source/authority inventory.
3. Evidence inventory and rawness classification.
4. Gate-by-gate challenge matrix.
5. Confirmed findings.
6. Evidence gaps.
7. Internal Oracle disagreement matrix.
8. Gate Calibration Failure check.
9. Claim ceiling.
10. Recommended route: `CONTINUE | RESUME_SMALLEST_REPAIR | META_ORACLE | DOMAIN_OWNER | HITL | TERMINAL`.
11. Files/evidence requiring human inspection.
12. Report SHA-256/readback when produced in a file-capable environment.

A challenge report is evidence about the review process; it is not automatically the canonical release decision.

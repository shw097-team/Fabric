# Method

1. **Gate-1 route.** Live named-method registry (`src/hg_kseos/named_methods.py`, `registry_snapshot()` +
   `route(flow)`), measured flow `RESEARCH_LITERATURE_REPO`, with `PURE_QA_CHAT` as an unrelated-flow
   negative control so that a constant router is detectable. The exact route string and reason code are
   recorded as measured, whatever they are; the previous run's label is not copied. Receipt: `ROUTE_CHECK.json`.
2. **Two independent reconnaissance sub-agents, in parallel with the writer lane.** They are not
   synthesizers: each writes exactly one artifact from primary sources and states what it could not determine.
   - W1 residual universe: every residual / gap / blocked / owner-decision / unlanded-candidate item, with
     the locator it came from and an explicit still-open check, de-duplicated across the acceptance report,
     the previous round's own receipts, the seven errata and the prior FAR runs, plus live GitHub state.
   - W2 defect dossier: the lane binary-pin defect and the T2 transport defect, each reproduced with raw
     output; the **checker-isolation feasibility measurement** (can an OS-enforced write denial be
     demonstrated on this host, probe dirs and ACLs cleaned up afterwards); and the skill's dangling-reference
     claim verified pointer by pointer.
3. **The rule is derived from those artifacts plus this round's own measurements**, and is stated as a ranked
   action set where every action carries: friction, feasibility, necessity, an over-engineering ruling, the
   alignment claim, and the authority it needs.
4. **Execution of the ruling, not of a plan.** The owner pre-authorized execution, so every action the ruling
   marks executable-now is executed on the lane chain; every action marked owner-gated is *prepared* in
   one-action form and **not** executed. The dividing line is authority, not difficulty.
5. **Writer and checker on different model axes.** EXECUTE on the Codex CLI arm
   `opencode-go/deepseek-v4.1-flash`; VERIFY_SECURITY pinned to `openai-codex/gpt-6.1-sol` at rank 2 with
   `--require-arm`, because the pool's rank-1 arm is the writer's own model. The registry is read, never
   edited, to make a measurement come out right. PLAN / orchestration leaves run on the mandated
   `openai-codex/gpt-6.1-sol`.
6. **Every count derived from artifacts on disk**; the evidence pack is generated by a script, not hand-written,
   and a number that lives only in the report is treated as unverifiable.
7. **Falsifiability first.** Any probe this round lands must ship with a case that makes it fail, and any
   guard must be shown failing before it is shown passing.
8. **Owner-gated means prepared, not attempted.** Merge, release, cross-repo code promotion, canonical
   control-plane edits and product-host ACL changes are handed over as one-action forms with their authority
   named; an agent pre-authorisation does not convert them into agent work.
9. **Closeout and handover as first-class products**, not as an afterthought: a checkpoint carrying the exact
   subject identity, the open tickets, the owner decisions, the rollback pointer and the next legal action,
   plus a single evidence MD mirrored byte-identical to the review roots with SHA-256 equality.
